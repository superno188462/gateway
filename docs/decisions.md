# 项目决策记录

## D-001：第三方能力先使用 Mock

- 状态：已决定
- 决策：LLM、Embedding、ASR、TTS 等第三方接口先通过可替换的 Mock Adapter 完成契约、界面和端到端流程。
- 原因：真实供应商和模型尚未选定，不应阻塞核心网关能力，也不应让供应商 SDK 渗透业务层。
- 后续：选择真实 Provider 后在 Mock 网关稳定后单独规划真实集成，并保留 Mock 用于自动化测试。

## D-002：网关暴露公网

- 状态：已决定
- 决策：Agent API 和管理控制台均按公网服务设计。
- 影响：生产入口必须使用 HTTPS，并落实反向代理信任边界、CORS allowlist、限流、请求大小限制、敏感信息脱敏和非必要端口关闭。

## D-003：唯一管理员支持环境变量引导和数据库续用

- 状态：已决定
- 决策：管理员用户名和密码环境变量必须同时配置或同时缺省。两项均配置时，应用以事务方式创建或覆盖同步数据库中的唯一管理员；两项均缺省时，直接使用数据库已有管理员，不修改账号信息。
- 首次启动：环境变量缺省且数据库没有管理员时启动失败，并提示配置管理员引导信息。只配置用户名或只配置密码时也启动失败。
- 持久化：管理员成功写入数据库后可以移除 `.env` 中的管理员配置，后续启动继续使用数据库记录。密码只保存安全哈希。其他用户通过业务流程写入数据库。
- 约束：数据库必须保证最多一个管理员。发现异常的多个管理员且无法安全自动修复时，应用启动失败并输出不含敏感数据的诊断。

## D-004：费用暂不作为第一版核心指标

- 状态：已决定
- 决策：第一版重点展示 token 消耗。币种为人民币，没有价格配置时 API 返回 `null`、前端显示 `-`。
- 后续：使用版本化 JSON 价格表配置不同模型的计价单位与价格，调用时保存价格版本和费用快照。

## D-005：日志保留采用时间和数量的并集

- 状态：已决定
- 决策：保留所有最近 30 天的日志，同时保证全系统最新 10,000 条日志始终保留。
- 示例：最近 30 天有 6,000 条，则继续向前保留到 10,000 条；最近 30 天有 50,000 条，则 50,000 条全部保留。

## D-006：默认不保存提示词和回复正文

- 状态：建议默认，等待产品负责人需要时调整
- 决策：普通调用日志不持久化用户提示词和模型回复全文，只记录用量、字符数、模型、状态、延迟、错误分类和追踪标识。
- 原因：提示词和回复可能包含个人信息、账号数据、源代码、合同内容或其他业务机密。公网网关长期保存全文会增加泄露和合规风险。
- 后续：若需要内容调试，设计按项目显式开启的短期诊断功能，并加入脱敏、加密、访问审计和独立保留期。

## D-007：本地开发不依赖 Docker

- 状态：已决定
- 决策：本地开发分别运行服务；后端使用 `uv run python main.py`，前端在 F0 完成后使用 `npm run dev`。
- Docker：仅提供服务器部署所需的 Dockerfile、Compose 和配置脚本，本机测试不以 Docker 为前置条件。

## D-008：统一认证入口，按角色授权

- 状态：已决定
- 决策：普通用户和管理员统一通过 `/api/v1/auth/*` 完成认证；JWT 携带角色标签。平台级管理接口可要求 `role=admin`；项目等资源操作按项目可见性、成员关系和 owner 身份授权，不因全局 admin 角色自动获得写权限。
- 原因：认证负责确认身份，授权负责判断权限，不能用不同登录 URL 固化角色边界。
- A1 范围：当前只实现唯一管理员引导；普通用户记录和普通用户权限将在后续阶段接入同一套认证流程。

## D-009：项目创建、可见性与管理员审阅权限

- 状态：已决定
- 决策：所有已登录用户都可以创建项目，创建者自动成为项目 owner。项目默认私有，也可以设置为公开。公开项目对所有已登录用户开放只读 review 权限；私有项目对 owner 和显式加入的成员开放。管理员可以 review 所有项目，但全局管理员身份本身不授予编辑或成员管理权限；管理员若是项目 owner，则按该项目的 owner 权限管理。
- 实现：公开项目使用可见性规则授予只读访问，不为每个用户创建冗余成员关系；成员表仅保存 owner 和显式授权成员。

## D-010：项目标签与列表检索

- 状态：已决定
- 决策：项目标签由 owner 自定义，不设封闭的固定标签集合；每项目最多 5 个标签，每个最多 20 个字符。写入时去除首尾空格、统一小写并在项目内去重。界面展示已有标签建议，允许 owner 新增自定义标签。
- 检索：项目列表提供关键词、标签和状态筛选，并使用服务端分页。查询始终先按公开/私有和用户成员权限过滤；管理员只对其可 review 的结果进行筛选。
- 数据：使用 `project_tags` 关联表保存标签，支持索引和精确匹配；未来若需要固定业务统计维度，再单独增加分类字段。
