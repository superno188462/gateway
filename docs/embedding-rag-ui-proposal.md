# Embedding / RAG 控制台页面提案

本文件是前端实现页面契约。用户已确认 Embedding 管理页沿用 LLM 样式，RAG 知识库页面由项目自行设计。

## 管理员：Embedding API

侧边栏“服务”下新增管理员可见的“Embedding API”，页面按 LLM API 的现有创建和分组样式实现：

- 连接组字段：供应商名称、连接名称、模型路由前缀、Base URL。
- API Key 文本框支持每行一个 Key；前端逐个创建连接，某个 Key 失败不阻止其他 Key。
- 已保存连接显示连接名、前缀、URL、优先级、密钥已配置状态、最近测试结果；允许查看本人可管理的完整上游 Key，支持测试、编辑、禁用、删除和优先级调整。
- 适配器能力明确显示“文本 Embedding（当前可用）”；图像/视频显示“需要多模态模型适配器，当前未接入”，不允许误配成普通文本请求。
- 页面说明调用方使用 `/v1/embeddings`、项目 API Key 和 `prefix/model`；不展示项目成员的 API Key。

## 项目成员：RAG 知识库

在当前服务项目列表模式下增加“RAG 知识库”入口；先选择有 RAG 服务订阅的项目，再进入该项目知识库页面：

- 知识库列表卡片展示名称、固定 Embedding 模型、文档/切片数量、向量维度和创建时间。
- 新建知识库表单包含名称、描述、模型、切片长度、重叠长度；模型来自 Embedding 前缀目录。说明一个知识库固定一个模型/维度，切换时要新建并重新嵌入。
- 知识库详情包含“文档”列表、“添加文本”表单和“检索测试”面板。列表展示文档标题、external_id、切片数、时间和删除操作；写入后显示处理状态与切片数量。
- 检索测试填写 query、top_k，结果逐条展示标题、相似度分数、切片正文和 metadata；只做检索，不自动调用 LLM。
- owner/editor 可以管理；viewer 可以只读查看知识库和文档，不能新增、编辑、删除或触发计费的检索测试。owner 可在项目详情页申请开通 RAG 服务。
- UI 走登录态项目管理 API；调用方运行时继续通过项目 API Key 调 `/v1/rag/*`。页面不要求用户粘贴自己的项目 API Key。

## 页面状态

新增、编辑、测试、禁用、删除和检索都应有 loading、成功、失败、空状态和确认提示。页面不得在浏览器持久保存第三方上游 Key，也不得将正文或 API Key 写入前端日志。

当前实现范围：Embedding 管理页提供按组录入、多 Key、测试、编辑、优先级、启停和删除；项目详情页提供 RAG 入口及服务申请，RAG 页面提供知识库、文本和检索管理。登录态 API 服务端校验项目成员角色；项目 API Key 运行时 API 保留给业务集成。
